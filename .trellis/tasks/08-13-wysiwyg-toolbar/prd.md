# ② 所见即所得工具栏：图片/代码块/表格（需求 8-11）

## Goal

工具栏按钮按下后直接呈现格式效果，不再插入裸语法文本。核心：把「插入语法」改成「插入即渲染」——图片选择文件后直接显示图片、代码块显示可输入代码框 + 语言选择、表格显示真实可编辑表格（可增删行列）。

## Requirements（来自 parent PRD 需求 8-11）

8. 通用原则：按钮按下后直接呈现格式效果，而不是插入裸语法文本
9. 图片：点击后打开电脑文件选择弹窗，插入后直接显示图片
10. 代码块：插入一个可输入代码的代码框，且可选择常见语言
11. 表格：插入一个真实表格（可编辑、可增删行列）

## Notes

- **依赖 ①（perf-smoothness）**：必须等 ① 合并后启动——Widget/复杂装饰需要性能基线（避免在卡顿编辑器上加重渲染），且 ① 的语法树是 Image/Table/代码块 Widget 的结构基础（节点定位、范围替换）
- 交互设计参考：Typora（图片插入即显示、代码块围栏语言选择器、表格右键增删行列）；Obsidian Live Preview 同思路
- 技术预研方向（启动时验证）：
  - 图片：utools 文件选择 API（showOpenDialog 或 utools 插件 API）→ 插入 markdown 图片语法 → Image 节点装饰为 Widget 显示图片
  - 代码块：FencedCode 节点区域装饰为代码框 + 语言选择条（CM6 官方 widget 模式）
  - 表格：Table 节点装饰为真实 table + 单元格编辑（范围替换 widget + 点击进入编辑态）——复杂度最高，可能拆子步
- 增删行列的交互方式（右键菜单 / 悬浮工具条）启动时与用户确认
