# UI 明暗对比与布局微调（侧边栏/标题/卡片）

## Goal

5 项 UI 样式调整：侧边栏变浅、视图分隔符、活跃对象/钉住标签对半分、标题加粗加大+分隔线、笔记卡片浅灰底。纯样式任务，不改交互逻辑与数据流。

## Requirements

1. **侧边栏变浅**：侧边栏背景从 `#f0f0f0` 改为 `#f7f7f8`（浅色模式；index.css 中 hex/oklch 双写需同步，oklch 为生效值，换算约 `oklch(0.9785 0 0)`）。深色模式不动（用户浅色满意后再调整）。
2. **视图栏分隔符**：ViewSwitcher 三个视图（首页/标签/归档）之间用浅灰色 `|` 竖线分隔（Separator 组件）；悬停与选中（点击）状态视觉要明显——侧边栏变浅后原选中白底对比变弱，需增强（如选中用 accent 底色 + 文字加深，悬停底色加深）。
3. **活跃对象 / 钉住标签对半分**：两组各占侧边栏可用高度一半（flex-1），中间固定间距（不要分隔线）；内容多时整体滚动（外层 ScrollArea 已有），不压缩对方区域。
4. **标题与分隔线**：
   - 右侧内容区标题改粗体（font-semibold）+ 字号加大（0.9rem → ~1rem），覆盖 ContentHeader 所有分支（默认/编辑态/ObjectHeaderActions 对象标题）。
   - 标题栏底部加一条细分隔线（border-b）。
   - 侧边栏视图栏底部加同款细分隔线，两条线齐平（两侧顶栏均 h-11，border-b 即齐平）。
5. **笔记卡片浅灰底**：笔记卡片背景改非常浅的浅灰（如 `#fafafa` / `--muted` 附近），**列表区域背景保持白色**（用户澄清：卡片浅灰、背景白）；卡片去掉边框（无边框），靠明暗区分。

## Constraints

- 仅浅色模式改动；深色模式（.dark）保持原样。
- 不改变组件 props、store、路由、交互逻辑。
- 不改功能文案与数据。
- 800×600 紧凑窗口下不得引入横向滚动或布局破坏。

## Acceptance Criteria

- [ ] 浅色模式下侧边栏背景为 #f7f7f8（肉眼确认），深色模式不变
- [ ] 视图栏三个视图间显示浅灰 `|` 竖线；悬停有可见底色变化，选中态明显区别于未选中（对比度可感知）
- [ ] 首页侧边栏：活跃对象区与钉住标签区各占一半高度，中间固定间距、无分隔线；对象/标签多时列表整体可滚动，两区不互相挤压
- [ ] 右侧标题（默认/编辑态/对象详情）均为粗体且字号大于 0.9rem
- [ ] 标题栏底部有细分隔线，与侧边栏视图栏底部分隔线水平齐平
- [ ] 笔记卡片为非常浅的浅灰底、无边框；列表区域背景为白色；hover/选中反馈仍清晰可见
- [ ] 全部改动后 ui-smoke / 现有测试通过（如项目有对应检查命令）
