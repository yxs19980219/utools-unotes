# PRD：侧边栏/顶栏/列表 UI 细节调整（round 2）

## 背景

用户对首页布局（侧边栏 + 内容区）提出 5 项视觉/交互调整。第一轮交付后，用户对其中 3 项给出修正反馈（选中态颜色、删除项红色、悬停动效），本轮为修正后的最终交付。

## 需求（最终版）

1. **侧边栏行背景色**（`SidebarRow.tsx`）
   - 悬停：`bg-accent`（原选中色，比原 hover 的 `bg-muted` 明显）
   - 选中：`bg-border`（比悬停更深的灰，非白色）
   - 覆盖对象行与标签行（共用 SidebarRow，全侧边栏一致）

2. **钉住标签操作入口**（`SidebarList.tsx` / `TagRowActions.tsx`）
   - 钉住标签行右侧 ⋯ 按钮删除，改为右键菜单（编辑别名 / 钉住|取消钉住 / 删除标签），与活跃对象行交互一致
   - 标签视图的 ⋯ 菜单保留
   - 删除项样式：非悬停红字、悬停**红底白字**（文字清晰不遮）；活跃对象右键、钉住标签右键、标签 ⋯ 菜单三处统一

3. **字号统一**：侧边栏「活跃对象」「钉住标签」分组标题由 12px 改为与其下内容一致的 14px（`text-sm`）

4. **标签语境笔记计数上移**（`ContentHeader.tsx` / `ContentArea.tsx` / `stores/notes.ts`）
   - 删除列表上方的「跨对象笔记 · N」独立行
   - 顶栏标签名右侧显示「笔记 · N」（与对象详情同理），数量与列表同源（来源筛选后），随筛选联动
   - 新增共享纯函数 `filterNotesBySource`（notes store），两处消费

5. **笔记卡片悬停动效**（`NoteCardList.tsx`）
   - 删除 `transition-colors`、`hover:shadow-sm`（浮起阴影）、编辑/删除按钮 hover 弹出（挤压标题）
   - 按钮改为常占位 + opacity 瞬时切换（无过渡动画、不挤压布局）
   - hover 时仅背景变色 + 按钮淡显

## 验收标准

- [x] 侧边栏行 hover 浅灰（accent）、选中深灰（border），层级清晰
- [x] 钉住标签行无 ⋯ 按钮，右键弹出与活跃对象一致的菜单
- [x] 三个删除菜单项悬停红底白字，文字清晰
- [x] 分组标题与行内容同字号
- [x] 标签语境顶栏显示「笔记 · N」，与列表数量一致（含来源筛选）
- [x] 卡片 hover 无过渡动画、无阴影、标题不跳动
- [x] `npm run typecheck`、`npm run build`、`npm run smoke:stores` 通过

## 范围

- 不改：标签视图（⋯ 菜单保留）、搜索态计数行、归档视图
- 不改数据层/存储语义（仅新增一个纯函数）
