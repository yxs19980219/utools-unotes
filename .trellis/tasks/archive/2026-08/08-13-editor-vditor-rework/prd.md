## Goal

用户 4 块需求：工具栏样式、标签+元信息布局、工具栏按钮所见即所得化（图片/代码块/表格）、内容区渲染细节（标题 # 大小、列表层级 marker、软换行、流畅度）。已确认换 Vditor IR 引擎（Typora 同款即时渲染），体积实测 +715KB~980KB zip（Lute 引擎为硬成本，hljs 用 10 语言子集），用户接受。

## Requirements

1. **工具栏样式**：快捷操作按钮栏上下用两条细线包住（border-y），不再裸在外面
2. **笔记头部布局**：
   - 标题字号加大（当前 text-sm 偏小）；标签改为**小字号紧跟标题后排列**（flex-wrap，超长才折行）；无标签时标题独占，不留空行
   - 删除「更新于」文字
   - 工具栏最右侧放一个**圆形感叹号按钮**，点击弹元信息面板：创建时间 + 更新时间 + 字数 + **可点击跳转的大纲列表**（按 H1-H6 层级缩进）
3. **工具栏按钮所见即所得**（按下后直接看到格式效果，不再插入裸语法）：
   - 图片：点击弹出**系统文件选择**（uTools 环境 showOpenDialog；dev 环境 input[type=file]），图片 base64 内嵌，插入即显示
   - 代码块：插入后是可输入代码的代码框，**可选择常见语言**（语言列表收敛为常用十余种）
   - 表格：插入**真实表格**（点击单元格直接编辑，快捷键增删行列——vditor 内置，已与用户确认）
   - 其余（加粗/斜体/标题/列表/引用/行内代码）：插入后立即渲染
4. **内容区渲染细节**：
   - 标题输入 # 号大小跟随标题级别（1 个 # 大、2 个 # 略小…）
   - 无序/有序列表与行首有距离；Tab 嵌套后缩进距离更大（层级清晰）
   - 列表嵌套层级 marker 符号变化：实心圆点 → 空心圆点 → 实心方点
   - 超长行按视口宽度自动换行（软换行）
   - 输入流畅度显著改善（当前每次击键全量重渲染 + 写盘是卡顿根因）
5. **实时保存**：沿用现链路（防抖 500ms 落盘 + 卸载 flush + Ctrl+S），数据格式仍为 Markdown 纯文本（db 兼容，无迁移）

## Constraints

- 离线可用：vditor 运行时动态加载的资源（Lute 引擎、代码高亮、i18n）必须本地化进插件包，禁止走 CDN
- 归档（只读）笔记保持现有 MarkdownView 渲染，不引入 vditor 预览
- 暗色主题与系统偏好联动（项目机制：html.dark 类），vditor 主题须同步切换
- 体积接受度已确认（+~800KB zip 量级），不做硬性预算
- 只改编辑区与 NoteView 头部，不动数据层/对象域/标签域
