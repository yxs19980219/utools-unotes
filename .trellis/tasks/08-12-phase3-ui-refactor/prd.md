# SourceNote 三期：对象一维状态 + 视图顶栏统一重构

## Goal

二期交付后 UI 暴露结构性问题：①对象标题/操作分散在顶部栏与元数据条两层（重复+视觉乱）；②对象状态两维正交（pinned/archived）制造"活跃但隐身"对象（恢复后首页不可见，需重新钉住）；③顶部「新建▾」与详情「新笔记」入口重叠；④搜索按钮冗余（uTools 搜索条原生可用）；⑤对象标签是"死数据"（不参与任何过滤/搜索）。本期一次性重构：**对象状态一维化、每视图唯一顶栏、对象操作移入侧边栏右键、新建入口收敛、对象标签去除**。

## 用户已拍板决策（2026-08-12 讨论确认）

1. **对象去掉 pinned 维度**：对象只有 `archived` 一维（活跃/归档）；首页侧边栏 = 全部活跃对象（按更新时间倒序），分组标题「活跃对象」
2. **标签钉住保留**：主题关注维度，与对象状态正交，不动
3. **对象级操作 = 侧边栏对象行右键菜单**（编辑/归档/删除；归档视图行 = 恢复/删除），不另加悬停 ⋯
4. **顶部「新建▾」下拉删除**；新建对象入口 = 首页「活跃对象」分组标题右侧 `+`；新建笔记入口 = 对象详情顶栏「＋新笔记」（带对象上下文）
5. **搜索按钮删除**（uTools 子输入框注册保留，原生搜索条直接可用）
6. **对象详情顶栏唯一**：来源 Badge + 标题 + 笔记数 + 操作（排序/＋新笔记/归档/编辑/删除）；第二行小字保留来源元数据（作者·年份·URL）；删除元数据条与列表标题行
7. **来源筛选保留**：标签视图 + 搜索态（用户忘记提，已补确认：保留）
8. **标签视图纯笔记语境**：顶栏 = 标签名 + 排序 + 来源筛选；无任何新建入口；卡片保留对象名/来源角标
9. **NoteView 顶栏只含笔记自身信息**：返回 + 笔记标题 + 标签 + 更新时间（无对象名/对象操作——已在对象内，侧边栏选中态可见归属）
10. **对象标签去除**：对象表单删标签输入、对象详情不展示对象标签（旧数据字段保留不展示，无迁移）；标签语义只属于笔记
11. 归档对象详情顶栏只读态：标题 + 笔记数 + 元数据 + 「恢复」按钮（无新笔记/编辑/归档/删除）
12. 笔记详情返回链路保持（返回 → 对象详情）

## Requirements（按钮级交互）

### R1 状态模型一维化（objects 域）
- `NoteObject.pinned` 字段不再读写；`togglePinned`、`selectPinnedObjects`、`selectPinnedTags`（标签侧保留）拆分
- `objects.ts`：删除 togglePinned 与 create 默认钉住；`setArchived(true)` 不再有取消钉住联动；恢复 = `setArchived(false)` → 对象立即出现在首页活跃列表
- 首页活跃列表 = `selectActiveObjects`（`!archived`）按 `updatedAt` 倒序
- 旧数据兼容：残留 pinned 字段无害（不读取）；smoke-stores 断言更新

### R2 首页侧边栏（SidebarList）
- 分组一：「活跃对象」（全部活跃，updatedAt 倒序）；分组标题右侧 `+` 按钮（`size="icon-sm"`，`aria-label="新建对象"`，Tooltip「新建对象」）→ `startEditing('object', null)`
- 分组二：「钉住标签」（现状保留，含 ⋯ 菜单）
- 对象行：来源图标 + 标题，点击 → `selectObject`；**右键菜单（ContextMenu）**：
  - 编辑 → `startEditing('object', id)`
  - 归档 → AlertDialog「将归档《名称》？其下 N 条笔记将一并转为只读」→ 确认 `setArchived(true)`
  - 删除 → AlertDialog「删除对象《名称》？将删除该对象及其下 N 条笔记，不可恢复」→ 确认 `remove(id)`（级联，现状逻辑）
- 无活跃对象空态：Empty + CTA「新建对象」→ `startEditing('object', null)`（现状保留）

### R3 对象详情（ObjectDetail + ContentHeader 合并为唯一顶栏）
- ContentHeader 在对象详情语境（`selectedObjectId` 非空）渲染：
  - 第一行：来源 Badge + 对象标题（truncate）+ 笔记数（「笔记 · N」）+ 右侧操作：[排序▾][＋新笔记][归档][编辑][删除]
  - 第二行（有元数据时，小字）：作者 · 年份 · URL（现状元数据条内容，`text-xs text-muted-foreground`）
  - 归档对象（readonly）：第一行 = 来源 Badge + 标题 + 笔记数 + 右侧 [排序▾][恢复]；无新笔记/编辑/归档/删除；第二行元数据保留；标题旁「已归档（只读）」Badge
- ObjectDetail 组件删除自身元数据条与列表标题行，仅渲染笔记卡片流（NoteCardList）
- 「＋新笔记」→ `startEditing('note', null)`（NoteForm 预填当前对象）
- 排序菜单选项（updated/created/title；搜索态 relevance 逻辑不变）

### R4 标签视图
- 顶栏（selectedTagId 语境）：标签名 + [排序▾][来源筛选▾]（现状逻辑保留）；**无新建入口**
- 内容区：跨对象笔记卡片流（现状，卡片含对象名/来源角标/已归档角标）
- 侧边栏：全部标签 + 悬停 ⋯ 菜单（编辑别名/钉住/删除，现状不动）
- 标签管理语境无"新建标签"按钮：标签由笔记/对象标签输入自动创建（现状机制，本次对象侧去除后仅笔记侧创建）

### R5 笔记详情（NoteView）
- 顶栏：返回 + 笔记标题 + 标签 chips + 「更新于 xx」（现状）——**删除对象名链接**（归属由侧边栏选中态可见）
- 归档笔记：「已归档（只读）」Badge 保留
- 编辑态工具栏/保存/取消/草稿保护（二期逻辑全部保留）

### R6 搜索态
- ContentHeader 搜索按钮删除；`utools.setSubInput` 注册保留（App.tsx 现状）
- 搜索态顶栏：搜索结果 + [排序▾][来源筛选▾]（现状）

### R7 归档视图
- 侧边栏：已归档对象列表（现状：图标+标题+归档时间）；**行右键 = 恢复/删除**（AlertDialog 确认）
- 内容区顶栏：只读态（R3 归档分支）；恢复按钮 → AlertDialog → `setArchived(false)` → 回活跃并出现在首页
- 空态保留（无归档对象引导）

### R8 设置视图：不动（来源类型管理 + 偏好，二期交付）

### R9 对象表单（ObjectForm）
- 删除标签 TagInput 与 `resolveTagIds` 提交调用；表单字段 = 标题 + 来源类型 + 来源元数据（作者/URL/年份）
- 对象详情不再展示对象标签 chips（ObjectDetail 第二行只保留作者/URL/年份）

## Acceptance Criteria

- [ ] **AC1** 首页侧边栏显示全部活跃对象（含归档后恢复的对象，无重新钉住步骤）；分组标题为「活跃对象」
- [ ] **AC2** 「活跃对象」分组标题 `+` 点击 → 新建对象表单；无顶部「新建▾」下拉
- [ ] **AC3** 对象行右键菜单：编辑/归档/删除；归档与删除均有 AlertDialog 确认（含笔记数）；删除级联
- [ ] **AC4** 对象详情只有一个顶栏（标题+笔记数+元数据+操作），无重复标题、无「笔记 · N」列表行
- [ ] **AC5** 对象详情顶栏「＋新笔记」→ NoteForm 预填当前对象，保存后进入该对象详情
- [ ] **AC6** 归档对象详情顶栏只读态（无新笔记/编辑/归档/删除 + 已归档 Badge + 恢复按钮）；归档视图对象行右键 = 恢复/删除
- [ ] **AC7** 恢复对象立即出现在首页活跃列表（无需重新钉住）
- [ ] **AC8** 标签视图顶栏 = 标签名 + 排序 + 来源筛选，无任何新建入口；卡片含对象名/来源角标
- [ ] **AC9** NoteView 顶栏无对象名（仅返回+标题+标签+时间）
- [ ] **AC10** 对象表单无标签输入；对象详情无对象标签展示；含旧标签数据的对象正常打开（兼容）
- [ ] **AC11** 内容区无搜索按钮；uTools 子输入框搜索注册保留（代码级验证）
- [ ] **AC12** 全量 smoke 更新后全绿（smoke-stores 删除/改写 pinned 断言、新增一维状态断言）；ui-smoke 更新后全绿（新增右键菜单/新入口流程断言）；800×600 无横向滚动；`npm run build` 通过、dist 无 development 字段
