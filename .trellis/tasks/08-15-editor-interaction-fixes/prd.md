# 编辑器交互与样式修复（引用删除、高亮、下划线标签、标题间距、公式块、功能区联动）

## Goal

修复用户报告的 6 个编辑器问题，均位于 `src/components/Editor/`（AtomicEditor + 扩展 + 工具栏）：
1. 引用状态下删除键（Backspace）退出引用逻辑
2. 高亮（==text==）黄色背景渲染不可见
3. 下划线（<u>text</u>）点击后显示标签
4. 标题字号太小、标题分割线与正文间距过小
5. 公式块间距不统一（以源码行数为标准）+ 相邻公式块点击错位 bug
6. 点击正文相应位置时编辑功能区（工具栏）按钮联动高亮

## 现状验证结论（2026-08-15 实测）

| # | 验证结果 |

| 2 | `.cm-atomic-highlight` 装饰存在，但背景 = `--atomic-editor-accent-bright`（= foreground 黑白）20% → `color(srgb 0.1 0.1 0.1 / 0.2)` 几乎不可见，用户感知为"未渲染" |
| 3 | 下划线标签 `<u>`/`</u>` 恒隐藏（`underlineDecoration.ts`），光标在内容中时也不显示 |
| 4 | h1 computed font-size = 1.54em（偏小）；标题 `::after` 分割线在行底部，与下一行正文间距 0px |
| 5 | ① 相邻公式块：第一块 KaTeX 内容高（如 \sum/\frac）时 DOM 高 69px 远超 CM6 分配的 1 行高（28.9px），点击"第二块视觉顶部/第一块下方空白"命中第一块 DOM → 错误 reveal 第一块（"点击下面的回跳到上面的"）② 多行源码块 minHeight=N 行，视觉间距随源码行数变化，与单行块不一致 |

## Requirements

### R1 引用删除键退出（问题 1）
- 空引用行（行文本为 `>` 或 `> `，光标在行尾）按 Backspace：**一次按键**删除引用标记，该行回归正常（无 `>` 前缀）
- 引用内容行（`> 内容`）Backspace 仍按默认行为删内容；删至空引用行后再按 Backspace 退出引用
- Enter 退出引用行为（现 `exitBlockquoteOnEnter`）保持不变
- 不破坏：嵌套引用（`> > `）、列表续行、普通行 Backspace

### R2 高亮黄色渲染（问题 2）
- `==text==` 渲染为黄色背景高亮（非光标行；光标行沿用现有 reveal 规则显示源码）
- 浅色/深色主题下均清晰可见
- `==` 标记非光标行隐藏（现状保持）

### R3 下划线点击显示标签（问题 3）
- 光标位于 `<u>…</u>` 区间内（含标签字符本身）时，`<u>`/`</u>` 标签显示为源码（可见）；内容仍有下划线
- 光标移出后标签恢复隐藏
- 只读模式下恒渲染（标签隐藏）

### R4 标题字号与间距（问题 4）
- h1/h2/h3 字号适度增大（目标：h1 ≥ 1.7em 视觉层级明显，h2 ≥ 1.45em，h3 ≥ 1.25em，等比微调 h4-h6）
- 标题行底部分割线与下方正文的间距 ≥ 0.25em（通过增大标题行 padding-bottom 实现）
- 标题上方间距同步适度增大（padding-top）
- 不破坏 CM6 行高映射：line-height 保持 ~1.3 比例、padding 总量控制在 atomic 同量级

### R5 公式块间距统一 + 点击修复（问题 5）
- **间距**：公式块与上/下文字、公式块与公式块之间的垂直间距视觉一致，**不以源码占行为标准**——渲染高度由内容决定（KaTeX 实际高度 + 统一 margin），多行源码块不产生多余空白
- **点击**：点击某个公式块（渲染结果）→ 光标进入该块源码（reveal）；相邻块/高内容块不产生错位（点击第二块绝不 reveal 第一块）
- 光标行 reveal 源码、Enter/方向键行为、滚动定位不回归（现有 smoke 覆盖项）

### R6 工具栏联动（问题 6）
- 光标/选区位于以下格式内时，工具栏对应按钮点亮（红色系高亮）：
  - 标题 h1/h2/h3（行首 `#`/`##`/`###`）
  - 加粗、斜体、下划线、删除线、高亮、内联代码、链接
  - 引用、无序/有序列表、勾选框
- 光标移出后熄灭；无光标格式时不点亮任何按钮
- 只读模式无工具栏（现状）

## Acceptance Criteria

- [x] AC1 空引用行行尾按 Backspace 一次 → 行内 `>` 消失，行回归正常（短文档、长文档（600 行）中均生效）
- [x] AC2 `==高亮文本==`（光标不在该行）渲染背景色为黄色系（浅色/深色主题 computed background 含明显黄色分量，非近黑/近白）
- [x] AC3 光标移入 `<u>下划线文本</u>` 内容区 → 行内可见 `<u>` 与 `</u>` 标签；光标移出 → 标签隐藏；下划线始终存在
- [x] AC4 h1 computed font-size ≥ 1.7 × 正文；h1 分割线（::after）与下一行正文间距 ≥ 0.25em；h2/h3 等比
- [x] AC5a 文档含单行块 `$$x$$` 与多行块 `$$\n…\n$$`：渲染态所有公式块视觉高度由内容决定（多行块不产生 ≥2 行空白）；块与上/下内容间距一致（±0.15em 内）
- [x] AC5b 两个相邻单行公式块（第一个为高内容如 `$$\sum_{n=1}^{\infty}\frac{1}{n^2}$$`，第二个 `$$x^2+y^2$$`）：点击第二块任意可视区域 → 仅第二块 reveal（源码显示），第一块保持渲染；点击第一块 → 仅第一块 reveal
- [x] AC6 点击 `# 标题` 行 → 工具栏"一级标题"按钮红色高亮；点击 `## ` → "二级标题"；点击 `**加粗**` 内 → "加粗"高亮；点击正文 → 无按钮高亮
- [x] AC7 现有 `npm run smoke:editor` 32 项全部通过（回归）
- [x] AC8 `npm run typecheck` 通过

## Constraints

- 不改动 NoteView 与 AtomicEditor 对外契约（props/ref 保持兼容；R6 需要新增 prop 时向后兼容）
- 不动 @atomic-editor/editor / @codemirror 包源码（本项目有 patches/ 目录，patch-package 可用，但优先自研扩展内解决）
- 主题颜色沿用项目语义 token 体系（atomicTheme.css 变量映射模式），高亮黄色可用新 token
- 工具栏按钮复用现有 shadcn Button + Tooltip，不引入新组件库
