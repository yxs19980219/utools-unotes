# ③ 头部布局与元信息面板（需求 2-7）

## Goal

优化笔记头部：标题字号加大、标签排版改进、删除「更新于」、新增 ⓘ 元信息面板（创建/更新时间、字数、大纲跳转）。

## Requirements（来自 parent PRD 需求 2-7）

2. 标题字号加大（当前偏小）
3. 标签改为小字号、紧跟标题后排列；一行放不下时才折到第二行
4. 没有标签时标题独占一行，不留空行
5. 删除「更新于」文字
6. 编辑功能栏最右侧放一个圆形感叹号按钮（ⓘ）
7. ⓘ 点击弹出元信息面板：创建时间、更新时间、字数、可点击跳转的大纲列表
